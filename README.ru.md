# CLTools — инструменты для исследования и спидрана Disney's Chicken Little (PC, 2005)

[English](README.md) · **Русский**

Набор для спидраннеров и исследователей PC-версии (Steam) *Disney's Chicken Little*: FPS-лок,
замедление / пауза / покадровый шаг, координаты игрока и телепорт, **скрытые триггеры и настоящая коллизия прямо
в игре**, уцелевшие части **дебаг-меню разработчиков**, свободная камера, просмотрщик карт, покадровый «чёрный ящик»,
работа с архивами и заметки по реверсу. Есть и полный разбор **глюка зиплайна на высоком FPS**
([docs/ru/ZIPLINE_GLITCH.md](docs/ru/ZIPLINE_GLITCH.md)).

> Проект не связан с Disney и Avalanche Software. Нужна своя копия игры. В репозитории нет файлов игры,
> декомпилированного кода игры и её данных.

## Установка (2 минуты)

1. Скачайте **`CLTools-vX.Y.zip`** со страницы [Releases](../../releases).
2. Распакуйте его **в папку игры** (Steam → Chicken Little → Управление → Просмотреть локальные файлы), чтобы
   `d3d8.dll` оказался рядом с `Chick.exe` и появилась папка `CLTools`.
3. Один раз запустите **`CLTools\Setup.bat`** — он поставит нужные Python-пакеты (а если Python нет, предложит
   установить его через `winget`).
4. Запускайте игру из Steam как обычно.

Всё. FPS-лок, горячие клавиши, оверлей и свободная камера работают сразу, как только `d3d8.dll` на месте, даже без
Python. Удалить — стереть `d3d8.dll` и папку `CLTools`.

## Горячие клавиши в игре

| Клавиша | Действие |
|---|---|
| F5 | пауза / продолжить |
| F6 | один кадр вперёд (если игра идёт — ставит на паузу) |
| F7 | скорость игры 100 % → 50 % → 25 % → 10 % |
| F8 | оверлей вкл/выкл |
| F9 | скриншот → `CLTools/screens/` |
| F11 | **свободная камера**: I/J/K/L — движение, U/O — вниз/вверх, стрелки — поворот, Ctrl — быстрее |

Настройки — `CLTools/clhook.ini` (создаётся при первом запуске): `FpsTarget=60`, `Windowed=1`, `FixedStep`,
`SkipAttractDemo=1` (на титульнике не запускается демо-ролик), клавиши и т.д.

## Инструменты

| Инструмент | Запуск | Что делает |
|---|---|---|
| **Inspector** | `Inspector.bat` | главная панель (вкладки ниже) |
| **Map Viewer** | `MapView.bat` | карта уровня сверху: геометрия, все объекты, редактируемые стартовые точки, игрок со следом, живые дроны |
| **Рекордер** | `Record.bat` | покадровый «чёрный ящик» (состояние, клавиши, тросы, огни, адрес краша) → `CLTools/recordings/` |
| HOG-архивы | `py -3 -m cltools.hog list/extract/pack` | архивы игры `.hog` |
| DB-контейнеры | `py -3 -m cltools.dbl file.DBL` | список чанков `.DBL/.env/.adb/...` |

### Вкладки инспектора

* **Main** — цель FPS, скорость, пауза и покадровый шаг, фиксированный шаг времени; позиция / скорость / поворот
  игрока, телепорт (камера переезжает сразу), слоты позиций; watch-лист памяти с выводом в оверлей.
* **Debug menu** — что уцелело от дебаг-меню разработчиков: каркасный режим (видно сквозь стены), освещение, туман,
  вертексные цвета, текстуры, кости, искажения, режимы видимости/рендера/окклюзии, встроенный лимитер движка;
  читы игры (God mode, Big head, …); игрок (яйца, монеты, сложность, карточки); свободная камера.
* **World 3D** — рисует прямо в игре, её же камерой:
  * объёмы объектов уровня: дедбоксы, чекпойнты, триггеры уровня, камеры, звуковые/партикл-триггеры, пикапы —
    с именами;
  * **живые дроны-враги** сквозь стены (зелёный — спит, жёлтый — проснулся, красный — горит фонарь, серый — убит);
  * **скан коллизии**: тысячи лучей самого движка вокруг игрока → реальная поверхность, по которой ходит
    персонаж (невидимые полы и уступы тоже).
* **Zipline** — монитор глюка зиплайна (состояние тросов, окно NaN), предупреждение о динамических огнях,
  детектор аномалий (объекты с NaN / inf / огромными координатами), «симулировать NaN».
* **Levels** — таблица уровней; загрузка любого мира (например, под-уровней вроде `theatre`, которых нет в
  *Select Level*).
* **Script** — вызов любой из 1222 нативных скриптовых функций движка.

## Как устроено время

Игра считает физику по реальному времени кадра в **целых миллисекундах** (`GetTimeMs` @ `0x65FC10`), поэтому всё
зависит от FPS (на 60 FPS dt чередуется 16/17 мс). Встроенный 30-FPS лимитер движка в релизе выключен. CLTools
держит ровно `FpsTarget`; замедление масштабирует FPS и игровое время вместе; пауза и покадровый шаг дают ровно 1/60 с
на кадр, ввод в паузе не теряется.

## Для разработчиков

* Сборка прокси-DLL: `build.bat` (Visual Studio Build Tools, x86) → `build/d3d8.dll`.
* Распакованный exe для статического анализа: `DumpImage=1` в `clhook.ini`, один запуск игры, затем
  `py -3 scripts/rebuild_dump.py` → `dump/Chick_unpacked.exe` (база 0x400000, для Ghidra/IDA/REA).
  `scripts/re_helper.py` — быстрые xrefs и дизассемблер на capstone.
* Скрипты, на которых разбирался глюк зиплайна: `scripts/zip_*.py`, `analyze_zip.py`, `crash_report.py`.

## Ограничения

* Полноэкранный режим с прокси не проверялся (по умолчанию — оконный).
* Скан коллизии показывает пол (лучи вниз); стены видны как перепады, потолки — нет.
* Объёмы объектов — осевые боксы.
* Карта рисует боксы, а не меши (форматы моделей и текстур ещё не разобраны).
* Свободная камера меняет только вид: отсечение объектов игра делает по своей камере у персонажа.
* Адреса — для текущей Steam-версии `Chick.exe` (PE timestamp 1130358323).
* Пока игра запущена, `.hog`-архивы заблокированы.
